# 벤치마크 수치 검증 규칙 (Benchmark Verification Rule)

- 벤치마크 점수나 수치를 README 등 저장소의 표에 새로 기입하거나 업데이트할 때는, 사용자가 제공한 숫자라도 절대 맹신하지 않습니다.
- 반드시 `read_url_content` 등의 도구나 브라우저 도구를 사용하여 출처 URL(테크니컬 리포트, 리더보드 등)에 직접 접속합니다.
- 웹페이지나 문서 내에 해당 벤치마크 숫자가 실제로 존재하는지 **직접 눈으로(도구로) 읽고 교차 검증(Cross-check)**한 후에만 파일을 수정하고 커밋합니다.
